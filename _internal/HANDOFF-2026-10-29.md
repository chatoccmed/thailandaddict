## 3. แนวทางการทำงาน (บทเรียนที่ต้องใช้ต่อ)

### 3.1 การตรวจ = ต้องเลียนแบบผู้ใช้จริง
- **ตรวจ route ที่ Worker ตอบ ต้องส่ง `-H "Sec-Fetch-Mode: navigate"` ด้วยเสมอ** — ตั้งแต่ compat date 2025-04-01 Cloudflare ตอบ 404 ให้การคลิกจริงโดยไม่เรียก Worker ถ้า path ไม่ใช่ไฟล์ · curl เปล่าจึง "ผ่าน" ทั้งที่ผู้ใช้เจอ 404 (memory `worker-navigation-404`)
- ห้ามถอด `run_worker_first: true` ออกจาก `wrangler.jsonc` · ห้ามเอาไปใช้กับบัญชี chatmaliwan (Free 100k req/วัน)
- เขียนตัวตรวจ live **ก่อน** deploy แล้วพิสูจน์ว่ามันจับของผิดได้จริง (ตัวตรวจวีซ่าเคย "ผ่าน" ภาษารัสเซียเพราะไม่เคยแมตช์อะไรเลย)
- regex หลายภาษา: `\b` ใช้ไม่ได้หลังอักษรไทย/ซีริลลิก/จีน → ใช้ lookahead `(?!\p{L})`

### 3.2 Gate ที่ต้องเขียว (อยู่ใน `npm run deploy` แล้ว)
`check-entry-rules` (วีซ่า, exit 13 · ข้อมูลเก่าเกิน 120 วันก็แดง → **ตรวจแหล่งใหม่ทุก 4 เดือน, ครั้งถัดไปก่อน 2027-02-24**) → build → `check-page-coverage` → `check-file-count` (90,000)

### 3.3 Deploy / บัญชี
- `wrangler.jsonc` ปักไว้ที่บัญชี chatoccmed · ทางถอยไปบัญชีเก่า = `wrangler.A.jsonc`
- env ระดับ user `CLOUDFLARE_API_TOKEN` เป็นของบัญชีเก่า และ wrangler ใช้มันก่อน OAuth → **ต้อง `env -u CLOUDFLARE_API_TOKEN`** · ใช้ `wrangler login` (OAuth, ให้สิทธิ์แค่ chatmaliwan + chatoccmed) · token หมดอายุ ~1 ชม. → `npx wrangler whoami` รีเฟรช
- deploy ผ่าน `npm run deploy` เท่านั้น · รันเป็น background แล้วรอ notification (ไดรฟ์ E: ช้า, อัปโหลดอ่านไฟล์ ~40 นาที)
- โปรเจกต์อยู่บน E: (junction) · C: เหลือ ~6 GB จึงย้ายกลับ C: ไม่ได้ · **ห้ามลบผ่าน junction ด้วย rm -rf**

### 3.4 Git
- commit เฉพาะ path ของงานตัวเอง (`git commit -- <paths>`) เพราะมีหลาย session ใช้โฟลเดอร์เดียวกัน
- 🚨 **`git checkout <commit เก่า> -- <โฟลเดอร์>` ทับไฟล์ที่ถูกเพิ่มใหม่ทีหลังแบบเงียบ** (รอบนี้ทับ 22 ไฟล์ deck zh/ru ขึ้น live ~80 นาที) → หลังคืนไฟล์ ต้อง `git status --porcelain` หาตัว `M` ก่อน build ทุกครั้ง

### 3.5 ความลับ / เบราว์เซอร์
- ห้ามพิมพ์ค่า token/secret ออกจอ (`[ -n "$VAR" ]` ไม่ใช่ `${VAR:-x}`) · ห้ามวาง token ในแชท
- Claude in Chrome: owner ล็อกอินเอง / ยืนยัน 2FA เอง · Claude กดปุ่มที่ owner อนุญาตชัดเจนเท่านั้น · หน้าต่าง/แท็บที่อยู่เบื้องหลัง Chrome ไม่วาด → เปิดแท็บใหม่ใน group แทน
- owner สร้าง/บันทึก API token เองไม่สำเร็จหลายรอบ → อย่าวางแผนที่ต้องพึ่ง token ใหม่ ใช้ dashboard + `wrangler login` แทน

### 3.6 การสื่อสารกับ owner
- ถามการตัดสินใจ **ทีละข้อ** (AskUserQuestion หนึ่งข้อต่อเทิร์น) · ปุ่มตอบห้ามมีข้อความแบบ "ทำแล้ว/บันทึกแล้ว" ที่อ้างว่าเสร็จ — owner อาจกดโดยยังไม่ได้ทำ
- ตอบเป็นภาษาไทยเมื่อ owner เขียนไทย · รายงานผลตรงไปตรงมา รวมความผิดพลาดของตัวเอง
