Both files are strictly additive and reuse the EXACT proto3 recipes (same keyframe shapes, same mask primitives, same easing/timing, same shadow/blur values), only rebound to the real classes of the hotel / roundup / article / hub page types. No brand color, font-family, spacing, or structural rule is touched — all effects use only transform / opacity / filter / box-shadow / backdrop-filter, and everything is gated behind a full prefers-reduced-motion kill switch.

KEY SAFETY DECISIONS honoring the class-map warnings:
1. Mask-reveal targets a PRIORITIZED candidate list and splits only the FIRST match. The big white-on-photo VISUAL heroes (.rhero/.rl-page .hero h1/.phero/.thero/.ahub-hero, plus hotel .hi-name) are unique elements, so a subtle brand glow + reveal is safe there. The hotel true H1 (.sec-title) is SHARED with every section H2, so it is only used as the LAST-RESORT fallback and is NOT resized or glowed — the JS prefers .hi-name (the intended visual headline) ahead of it. DIV / shared candidates get an explicit .mrdy-host hook class instead of assuming a fixed element class. The setTimeout(…,140) failsafe is preserved verbatim.
2. Count-up rejects any node containing letters (latin OR Thai ก–๙), so mixed strings like the roundup/article "★ 4.8 · 1,234 รีวิว (source)" score pill are left untouched; it only tweens clean numeric displays (.qi-val, .pw-price, .pr-sc, .price-big, .stat-pill strong, .cstat .n, .resto-price .pv). It preserves currency prefix (฿), trailing suffix (/10, +), decimal places (9.1 stays 9.1) and thousands grouping, and guards NaN. It explicitly SKIPS .r-num and .rbar-fill, which the hotel layout already animates via its own observer — no double-animation.
3. Frosted glass uses the lighter proto3 .search-card frost on LIGHT-bg summary/booking cards (hotel .pw + .quick-answer, roundup .compare-top/.compare-section/.quick-answer/.article-meta-box, article .quick-answer, hub .qabox) and the heavier .stat frost on the hub .cstat strip, so text stays crisp.
4. Card grade/glow/shine + button gloss/shine are bound to each page's real image-card and CTA/booking classes. Booking buttons keep their brand fills untouched (Agoda/Booking/Trip/Klook) — only a translucent white sheen + moving highlight is overlaid via ::before/::after with isolation to protect stacking. On the roundup card, on-photo overlays (.img-overlay/.mrt-tag/.rd-img-book/.entry-save/.entry-badge) are re-asserted above the added legibility scrim so the full-cover book link stays clickable.

NOT-BROKEN checklist: does not add/remove .rv or .fade-up (those reveal observers are untouched); does not force opacity:1 on .rv; does not put transform/overflow on .rgrid or sticky ancestors (only on the cards themselves, which are not sticky); respects inline-styled colors (we never set color on rank/score/badge nodes); pseudo-element shine never blocks pointer events (pointer-events:none everywhere). Wiring: add <link rel="stylesheet" href="/css/premium.css"> and <script defer src="/js/premium-motion.js"></script> to the hotel/roundup/article layouts and the hub page() chrome (harmless if it also loads on the homepage since selectors are scoped to non-homepage classes).
