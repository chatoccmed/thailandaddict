Additive typography + spacing module for astro/public/index.html — append AFTER the main head <style> (post line 284) or as a new <style> at end of <body>. It changes NO brand color tokens and NO font-families (Outfit/Sarabun/Noto/Fraunces all stay; .stat .n stays Fraunces).

What it does:
- Fluid clamp() type scale as additive :root tokens (--ta-step-*), 320->1240px window, every step <=2.5x min (WCAG 1.4.4 safe). Applied to .hero-h1 (step-4), .stit (step-2), .ssub/.hero-sub (step-0 body 16->18px), .nl-h (step-3).
- Thai readability: raises body leading to 1.75-1.8 on .ssub/.why-b/.ft-desc and card titles, and — critically — bumps .hero-h1 line-height 1.06 -> 1.3 (and 1.34 on mobile) so Thai tone marks/vowels on Fraunces don't clip. Kept the eyebrow (.slbl/.h-eye) tiny + static at 0.72rem / 0.14em as a rhythm anchor (not fluidly scaled).
- Display tightening: negative letter-spacing on large Outfit/Fraunces headings (hero -0.02em, section -0.01em, .stat .n -0.01em); kickers +0.14em.
- Spacing: replaces flat 58px .sec padding with fluid --ta-section-y clamp(56px->120px) — the biggest premium lever; widens .inner cap 1120->1200px with clamp(18->40px) gutters; gives .s-head airier margin-bottom clamp(32->56px) and fixes the eyebrow->title->subtitle rhythm (16px / 12px); .s-head left cluster capped at 640px, .center variant centered.
- Includes mobile @media (<=560px) so it stays balanced (shorter hero, tighter heading leading) and an ultrawide clamp so prose doesn't run long.

Caveats:
1. .sec.pop flips heading COLORS light (lines 280-281); this module never touches color so that variant is preserved — I re-assert only line-height there.
2. .s-head > div assumes the left cluster (slbl+stit+ssub) is wrapped in a single <div> (the documented structure). If any section puts those bare children directly in .s-head, the max-width:640px cap won't apply to them — harmless, just no cap.
3. .s-head.center has no dedicated rule in the file and relied on markup; I added a real centered rule, which is an improvement but will now actively center any .s-head.center (verify the two usages at lines 393/511 look right).
4. Tokens are namespaced --ta-* to avoid any collision with existing --r/--sh etc. No motion added; js empty.
