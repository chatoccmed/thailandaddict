  2. เปิด หน้ารีวิว บนมือถือ แล้วสังเกตแถบราคาล่างจอ ปุ่มจองไม่ถูกแถบเมนูทับอีกแล้ว

  4. เปิด หน้าทริป แล้วลองย้ายรายการข้ามวัน ทั้งด้วยการลาก และด้วยเมนู ⋮ เมนูมีไว้เพื่อคนที่ลากไม่ได้

อะไรจริง อะไรยังเป็นของจำลอง

เขียนไว้ให้ครบ เพราะถ้าไม่บอก ต้นแบบจะดูเสร็จกว่าความจริงเสมอ

ของจริงในต้นแบบนี้

  • ชื่อ คะแนน ราคา รูป และลิงก์จอง ทุกตัวมาจากไฟล์เนื้อหาจริงใน astro/src/content/ และข้อมูลจังหวัดจริงใน _internal/province-data/
  • หน้ากระบี่มีการ์ดที่พัก 66 ใบและปุ่มบันทึก 74 ปุ่ม (นับจากหน้าที่โหลดจริง) ทุกใบเป็นโรงแรมที่เรารีวิวไว้จริง
  • หน้าอันดับมีตารางเทียบราคาจริง 10 แถว หน้าทริปมีบอร์ด 3 วัน
  • ลิงก์แอฟฟิลิเอตของจริง Agoda cid=1965862 · Booking ผ่านเส้นทาง /go/b ของ worker · Trip.com Allianceid=6861268
  • ปุ่ม 🔖 ตัวเลขบนแท็บทริป และข้อความแจ้งเตือน ทำงานจริงข้ามทุกหน้า เก็บใน localStorage ของเครื่องคุณ
  • บอร์ดรายวันย้ายรายการได้จริง ทั้งลากและผ่านเมนู ⋮ และคำนวณระยะทางสดจากพิกัดจริง
  • แผนที่ในหน้าทริปเป็นแผนที่จริงจาก OpenStreetMap โหลดเมื่อคุณกดเท่านั้น
  • ค้นหาใช้ดัชนีจริง 460 รายการ แบ่งเป็นจุดหมาย 95 · ที่พัก 130 · ที่กิน 75 · ไกด์ 95 · อันดับ 65
  • ส่งออกทริปเป็นไฟล์ JSON ไฟล์ปฏิทิน และเปิดใน Google Maps ได้จริง

ยังเป็นของจำลอง หรือยังไม่มี

  • ไม่มีฝั่งเซิร์ฟเวอร์เลย ไม่มีบัญชีผู้ใช้ ไม่มีการซิงก์ข้ามเครื่อง ทุกอย่างอยู่ในเครื่องที่คุณเปิด
  • ดัชนีค้นหา 460 รายการเป็นชุดย่อย ไม่ใช่ทั้งเว็บที่มีราว 18,100 หน้า
  • ทั้งเจ็ดหน้าเป็นไฟล์ HTML เขียนมือ ยังไม่ได้ผูกเข้ากับตัวสร้างหน้าจริง (gen-hubs.mjs และเลย์เอาต์ทั้งสามตัว) การผูกคือเฟส 2
  • ต้นแบบมีแค่ไทยกับอังกฤษ อีกเจ็ดภาษายังไม่ได้ทำในชุดนี้
  • ฟอนต์ Sarabun และ Outfit ชี้ไปที่ img.thailandaddict.com ซึ่งยังไม่มีอยู่จริง (โดเมนย่อยยังไม่ถูกสร้าง) ตอนนี้จึงตกไปใช้ฟอนต์ของเครื่องอัตโนมัติ ต้องอัปโหลดไฟล์ฟอนต์ก่อนโรลเอาต์
  • ลิงก์บางลิงก์ในเมนู เช่น “ใกล้ฉัน” ยังชี้กลับไปหน้าเว็บจริง เพราะยังไม่ได้ทำหน้าต้นแบบของมัน
  • ยังไม่มีปุ่ม “บันทึกไว้ใช้ออฟไลน์” ที่โหลดรีวิวกับรูปทั้งทริปมาเก็บล่วงหน้า อันนั้นอยู่ในเฟสถัดไป

สิ่งที่ต้นแบบนี้ตั้งใจไม่ทำ และจะไม่ทำตลอดไป คือข้อความเร่งให้รีบ ตัวเลขคนกำลังดูอยู่ นาฬิกานับถอยหลัง ส่วนลดปลอม และวันที่ตรวจสอบที่ไม่ได้ตรวจจริง ทุกวันที่ที่เห็นในต้นแบบมาจากฟิลด์วันที่จริงในไฟล์เนื้อหา
